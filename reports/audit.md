## 3. Honesty Rules Audit Findings

### Violation 1: Unmeasured "Real-Time" Label in README and API
- **Rule**: Do not use the word "real-time" in UI or docs unless `reports/latency.json` exists and its measured numbers are displayed next to the word.
- **Finding**:
  - `README.md` Title contained *"Real-Time Flood Prediction..."*
  - `src/api/main.py` description contained reference to real-time.
  - `reports/latency.json` does not exist yet (scheduled for Phase 19).
- **Remediation**:
  - Removed "Real-Time" claims from `README.md` and `src/api/main.py`. Replaced with descriptive phrasing: *"Tamil Nadu River Basin Flood Forecasting System (Academic Decision-Support Prototype)"*.

### Violation 2: Unlabeled Synthetic Forecast Curve in Dashboard
- **Rule**: No score, interval coverage, latency, or accuracy number is ever hardcoded or estimated. Any synthetic demonstration data must be unmistakably labelled and separated.
- **Finding**:
  - In `src/dashboard/app.py` (Forecast tab), when plotting observed river discharge, an artificial trace `last_val * 1.05` was appended and plotted as a dashed orange line labelled simply `"Predicted ({selected_model})"`.
- **Remediation**:
  - Replaced the hardcoded synthetic point with genuine model inference loaded from the trained model artifacts (`models/*.joblib`), or if model artifacts are not present, displaying an explicit banner: *"Run `python -m src.train` to generate model forecasts"*.

### Violation 3: Dropped Tabs in Streamlit Dashboard
- **Requirement**: The original **Rainfall Risk** and **District Comparison** tabs were missing from the Streamlit UI.
- **Finding**:
  - `app.py` previously had 6 tabs (`Overview`, `Forecast`, `Risk Decision`, `ML Model Comparison`, `Data Quality`, `About & Limitations`).
  - Missing: **Rainfall Risk** tab and **District Comparison** tab.
- **Remediation**:
  - Restored both tabs in `src/dashboard/app.py`.
  - In the **Rainfall Risk** tab: The IMD daily rainfall intensity indicator (Normal, Heavy, Very Heavy, Extremely Heavy) and the ML river discharge risk layer (Low, Moderate, High, Severe) are displayed **strictly side-by-side in separate columns**, and **never merged** into an unscientific single index.
  - In the **District Comparison** tab: Station river flow, catchment rainfall, and upstream/downstream geographical relationship across Cauvery basin districts are presented with clear statistical caveats.

### Violation 4: `beats_baseline` Claim Qualification
- **Rule**: Do not claim a model beats persistence unless formal significance testing (Phase 15) supports it.
- **Finding**:
  - `beats_baseline` was a simple boolean check: `rmse < persistence_rmse`.
- **Remediation**:
  - Added clarifying documentation and tooltip in the UI: *"Nominal lower RMSE only. Statistical significance testing is evaluated in Phase 15; do not interpret nominal lower RMSE as proven superiority."*

### Violation 5: Character Encoding in `__init__.py` files
- **Finding**: Several package `__init__.py` files triggered `CoverageWarning` about invalid encoding declarations on Windows PowerShell.
- **Remediation**: Re-encoded all `__init__.py` files to clean UTF-8 with standard package docstrings.
